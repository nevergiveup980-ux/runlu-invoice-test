# RUNLU Invoice Automation V1.0 — Alpha Build002

## What changed
- Billing period is freely selectable with a month picker.
- Invoice date and send date are independent and editable.
- Month-end dates can be recalculated using a weekend rule.
- Reminder and follow-up times are configurable.
- Previous invoice number and optional prefix are configurable.
- Dashboard shows the selected billing period, natural month end, invoice date, send date, reminder time, and next invoice number.
- Existing Build001 local profile data is migrated automatically when possible.

## Deploy to GitHub Pages
Upload every file and the `assets` folder to the repository root. Keep `index.html` at the root. Refresh the GitHub Pages URL after deployment.

## Important
This Alpha stores data only in the current browser/device using localStorage.
