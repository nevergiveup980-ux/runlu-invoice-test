# RUNLU Invoice Automation V1.0 — Alpha Build003

## Included
- Professional welcome screen
- Business Workspace creation
- Business Profile sections
- Logo upload and brand color
- Regional settings
- Configurable billing cycle and billing period
- Invoice, send, weekend, holiday and reminder rules
- Invoice prefix and automatic numbering preview
- Automation Preview
- Dashboard
- Configuration Center
- Local JSON backup export and restore
- PWA manifest and offline service worker

## Deploy to GitHub Pages
Upload every file and the `assets` folder to the repository root. Confirm that `index.html` is at the root, then refresh the Pages URL.

## Important
Data is stored in the current browser/device using localStorage. Build003 does not yet include cloud synchronization or Customer Manager.
