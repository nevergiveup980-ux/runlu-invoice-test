# RUNLU Invoice Automation V1.0 — Alpha Build 001

First executable foundation build.

## Included
- First-launch welcome screen
- Four-step Business Setup Wizard
- Business name, optional legal name and business number
- Logo upload (stored locally)
- Brand color selection
- Country, currency, language and date-format defaults
- Local browser storage
- Dashboard/empty state after setup
- Business profile JSON export
- Installable PWA files and offline cache

## Not included yet
- Customer Manager
- Recurring Billing
- Invoice/Word/PDF generation
- Email package and attachments
- Review Center
- History
- Cloud sync

## Test on GitHub Pages
Upload the contents of this folder to the root of your `runlu-invoice-test` repository. Keep `index.html` in the root. GitHub Pages should be set to `main` and `/(root)`.

## Reset local setup
In Safari, clear website data for the test site, or use a private tab for a fresh first-launch test.
